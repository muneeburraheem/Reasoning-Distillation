# Paper tables

The numbers on the results page (claude.ai artifact "ReasonDistill New-SAE Results"), one table per dataset.
Machine-readable copy: `paper_tables.json`. Each table names the summary file it was read from; those files are
regenerated by `scripts/run_all_analyses.sh` (see `results/README.md`). New-SAE RD = RD warm-started from LKD
epoch 1 with the retrained SAE; alpha 0.05 / 0.15 / 0.40 = low / moderate (RD_mod) / high. Differences are RD - LKD.
